# Conversation Summarize

Summarize the current conversation so the user can quickly recall context.

## Output Format

### Goals
What the user is trying to achieve.

### Key Decisions
Important choices that were made and why.

### Progress
What has been completed so far.

### Open Questions
Unresolved items or decisions still pending.

### Next Steps
What should happen next.

Keep it concise and structured. Focus on actionable information, not transcript.
